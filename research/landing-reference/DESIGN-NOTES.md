# Landing reference — retellai.com (extracted via Firecrawl 2026-07-03)

Raw evidence: `retellai-branding.json` (branding format), `retellai-content.md` (full page markdown).

## retellai brand (for reference only — we keep Kadai's own brand)
- colorScheme: light, white background (#FFFFFF)
- primary accent #FFBB7E (warm peach), secondary #3E6AEF (blue), ink #00122E (near-navy-black)
- buttons: near-black bg (#00122E), white text, 6px radius, no shadow → matches Kadai's near-black buttons
- fonts: "Untitled Sans" body + **Georgia serif for headings** (editorial feel), very large hero headings
- radius 12px, base spacing unit 4px
- personality: modern, medium energy

## retellai section rhythm (the layout we're replicating)
1. Sticky top nav: logo · nav links · Login / Contact Sales / **Try For Free** (primary)
2. Hero: oversized headline + one-line subhead + primary CTA + "trusted by" integration logo strip
3. "What is Retell?" — 3 capability cards
4. Live demo block (interactive product peek)
5. "Proven Impact, Real Conversations" — metrics + case-study cards
6. "Human-standard ... out of the box" — value statement band
7. "Effortless to Use, Highly Configurable" — 3 feature rows
8. "True omni-channel" — Voice / Chat / SMS / API tabs
9. Telephony stack + Enterprise security grids
10. Integrations grid
11. FAQ accordion ("Common Questions")
12. Footer CTA band + footer

## How we adapt it for Kadai (decision: same layout, Kadai brand)
- Keep Kadai Carbon tokens: near-black #161616 buttons, white canvas, Carbon blue #0f62fe accent, IBM Plex (NOT Georgia). Borrow retellai's oversized editorial headline sizing + generous whitespace.
- Tamil Nadu / India framing throughout: வணக்கம் greeting, ₹ pricing, WhatsApp-first, Tanglish testimonials, small-shop personas (fruit seller, salon, bakery, tailor).
- Section map → Hero → "What is Kadai" (Chats/Broadcast/Orders) → product peek (WhatsApp phone frame) → real-shop proof/testimonials → features → how-it-works (3 steps) → pricing (₹1500/mo, 14-day trial) → trust (official WhatsApp, your number) → FAQ → footer CTA.
